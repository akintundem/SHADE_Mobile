# Shade - Brand Guidelines

## Brand Identity

### Name
**Shade**

### Tagline
"Your private moments, shared securely"

### Mission
To provide a premium, secure platform for private sharing of thoughts, videos, and photos from exclusive events, with the ability to monetize experiences.

---

## Visual Identity

### Logo
- **Icon**: Umbrella (☂️)
- **Representation**: Protection, privacy, coverage, exclusivity
- **Usage**: Always displayed in brand purple (#8B5CF6) on light backgrounds, white on dark backgrounds

### Color Palette

#### Primary Brand Color
**Slate (#0F172A)**
- RGB: 15, 23, 42
- HSL: 222, 47%, 11%
- Usage: Primary actions, branding, active states, important UI elements
- Psychology: Ultra premium, sophisticated, professional, exclusive

#### Secondary Accent
**Amber (#F59E0B)**
- RGB: 245, 158, 11
- HSL: 41, 92%, 50%
- Usage: Highlights, special features, call-to-actions
- Psychology: Luxury, warmth, valuable, premium

#### Neutrals

**Light Mode (Eye-Friendly)**
- Background: #FEFEFE (Warm off-white, not harsh pure white)
- Surface: #F8F9FA (Soft gray surface)
- Card: #F1F3F4 (Warm card background)
- Border: #E1E5E9 (Softer borders)
- Text Primary: #1A1D21 (Softer black, less harsh)
- Text Secondary: #5F6368 (Warmer gray)
- Text Tertiary: #80868B (Medium gray)

**Dark Mode (GitHub-Style)**
- Background: #0D1117 (Not pure black, easier on eyes)
- Surface: #161B22 (Slightly lighter surface)
- Card: #1C2128 (Card background)
- Border: #30363D (Visible but subtle)
- Text Primary: #F0F6FC (Softer white)
- Text Secondary: #8B949E (Warm gray)
- Text Tertiary: #6E7681 (Medium gray)

## Voice & Tone

### Brand Voice
- **Premium**: High-quality, exclusive, refined
- **Secure**: Trustworthy, private, protected
- **Friendly**: Approachable, helpful, warm
- **Professional**: Polished, sophisticated, reliable

### Writing Style
- Use clear, concise language
- Emphasize privacy and security
- Highlight exclusivity without being pretentious
- Be confident but not aggressive
- Use "you" and "your" to speak directly to users

### Example Messaging
✅ "Your private moments, shared securely"
✅ "Discover curated moments and premium experiences"
✅ "Capture and share from exclusive events"
✅ "Premium & Secure"

❌ "The ultimate event platform" (too generic)
❌ "Share everything publicly" (contradicts privacy)
❌ "Basic event sharing" (undersells premium nature)

## Spacing

### Scale
- xs: 4px - Minimal spacing
- sm: 8px - Tight spacing
- md: 12px - Compact spacing
- lg: 16px - Standard spacing
- xl: 20px - Comfortable spacing
- 2xl: 24px - Relaxed spacing
- 3xl: 32px - Generous spacing
- 4xl: 40px - Large spacing
- 5xl: 48px - Extra large spacing

### Usage Guidelines
- Use lg (16px) for standard padding
- Use xl (20px) for comfortable breathing room
- Use 2xl (24px) for section separation
- Use 3xl (32px) for major section breaks

---

## Shadows & Elevation

### Shadow Levels
- **sm**: Subtle elevation for inputs
- **md**: Standard cards and buttons
- **lg**: Important cards and modals
- **xl**: Floating panels and popovers
- **brand**: Special brand elements (purple tint)

### Usage
- Use shadows sparingly for important elements
- Brand shadow for primary actions only
- Increase shadow on hover/press for feedback

---

## Animation & Motion

### Timing
- **Fast**: 150ms - Micro-interactions
- **Normal**: 250ms - Standard transitions
- **Slow**: 350ms - Complex animations

### Easing
- Standard: ease-in-out
- Spring: For natural, bouncy feel

### Principles
- Animations should feel smooth and natural
- Use subtle animations to guide attention
- Never block user interaction with animations
- Respect reduced motion preferences

---

## Accessibility

### Color Contrast
- All text meets WCAG AA standards (4.5:1 for body text)
- Large text meets WCAG AA (3:1)
- Interactive elements have clear focus states

### Touch Targets
- Minimum 44x44pt tap target
- Adequate spacing between interactive elements

### Typography
- Minimum body text: 16px
- Clear hierarchy with size and weight
- Sufficient line height (1.5 for body text)

---

## Do's and Don'ts

### ✅ Do
- Use the umbrella icon consistently
- Maintain purple as the primary brand color
- Use shadows for depth and hierarchy
- Keep messaging focused on privacy and premium quality
- Use SafeAreaView for all screens
- Use lucide icons with consistent stroke widths
- Test in both light and dark modes

### ❌ Don't
- Change the brand color to other hues
- Use multiple primary colors
- Overuse shadows (keep it clean and modern)
- Use generic stock photos
- Mix icon styles or libraries
- Hardcode colors or spacing
- Forget dark mode support
